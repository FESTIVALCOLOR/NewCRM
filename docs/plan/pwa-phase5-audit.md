# Фаза 5: Аудит Desktop vs Mobile PWA — Расхождения и план исправлений

**Дата аудита:** 2026-03-26
**Метод:** Параллельный анализ 4 агентами всех модулей

---

## КРИТИЧЕСКИЕ РАСХОЖДЕНИЯ (нужно исправить)

### P0: Проверки платежей при перемещении CRM карточки
**Где:** CrmBoardPage.vue `selectMoveColumn()`
**Проблема:** Мобиль НЕ проверяет оплату перед перемещением на стадии
**В десктопе (crm_tab.py:659-670):**
1. Аванс не оплачен → нельзя переместить на Стадию 1 (индивидуальные)
2. 2-й платёж не оплачен → предупреждение при перемещении на Стадию 3
3. Финальный платёж → диалог ожидания при завершении
**Оценка:** 2-3 часа
**Приоритет:** КРИТИЧЕСКИЙ — без этого возможна работа без оплаты

### P1: Перемещение карточек надзора
**Где:** SupervisionPage.vue
**Проблема:** Нет механизма перемещения карточек надзора между колонками (в десктопе — drag-and-drop)
**Решение:** Добавить long-press → диалог перемещения (аналогично CRM)
**Оценка:** 2-3 часа

### P2: Логин/пароль видны всем при редактировании сотрудника
**Где:** EmployeesPage.vue (форма редактирования)
**Проблема:** Поля логин/пароль видны всем с правом `employees.update`, а в десктопе — только для Руководителя студии
**Решение:** `v-if="isSuperuser"` на полях логин/пароль
**Оценка:** 15 минут

## ВАЖНЫЕ РАСХОЖДЕНИЯ (следует исправить)

### P3: Фильтры архива CRM
**Где:** CrmBoardPage.vue (архив)
**Проблема:** Архив показывает ВСЕ карточки без фильтров. Десктоп имеет фильтры: период, адрес, город, агент
**Решение:** Добавить сворачиваемый блок фильтров в режиме архива
**Оценка:** 2 часа

### P4: Глобальный поиск
**Где:** MainLayout.vue
**Проблема:** В десктопе есть GlobalSearchWidget (поиск по всему: клиенты, договоры, CRM). В мобильной версии — нет.
**Решение:** API `/api/v1/search/global` уже существует. Добавить иконку поиска в header → диалог с результатами
**Оценка:** 2 часа

### P5: Настройки уведомлений — расхождения
**Где:** MainLayout.vue (диалог настроек)
**Проблема:**
- Мобиль НЕ показывает: дублирование уведомлений от подчинённых, выбор сотрудника (для Директора)
- Мобиль ИМЕЕТ Email toggle (десктоп не имеет)
**Решение:** Добавить секцию «Дублирование» + выбор сотрудника для суперюзера
**Оценка:** 1.5 часа

### P6: Прямая ссылка на папку проекта на ЯД
**Где:** CrmCardPage.vue
**Проблема:** Десктоп показывает кнопку «Открыть папку на ЯД» для всего проекта. Мобиль — только для ТЗ.
**Решение:** Добавить кнопку «Папка на ЯД» в шапку карточки (из `contractData.yandex_folder_path`)
**Оценка:** 30 минут

## КОСМЕТИЧЕСКИЕ РАСХОЖДЕНИЯ (nice-to-have)

### P7: История исполнителей при назначении
**Где:** CrmBoardPage.vue (Шаг 2 перемещения)
**Проблема:** Десктоп показывает кто был назначен на предыдущих стадиях. Мобиль — нет.
**Решение:** Показать последних исполнителей в селекте (label с текстом "ранее назначен")
**Оценка:** 1 час

### P8: Поиск на CRM доске
**Где:** CrmBoardPage.vue
**Проблема:** Нет поиска по адресу/номеру/менеджеру на доске (нет и в десктопе)
**Решение:** Добавить поле поиска над pill-навигацией
**Оценка:** 1 час

## МОБИЛЬНЫЕ ПРЕИМУЩЕСТВА (не трогать, это улучшения)

Мобильная версия ЛУЧШЕ десктопа в этих аспектах:
1. Dashboard: приветствие, мои задачи, быстрые ссылки, уведомления
2. Клиенты: кнопки действий (звонок, email, Telegram, карты), договоры клиента
3. Договоры: фильтры (статус, тип, агент), загрузка чека
4. Надзор: бюджет (сводка), выезды, фотофиксация с камеры
5. Файлы: полный менеджер ЯД (breadcrumbs, upload, download)
6. Профиль: отдельная страница
7. Администрирование: полный модуль (тарифы, агенты, города, роли, нормодни)
8. Уведомления: список с фильтрами, кликабельные, badge
9. Pull-to-refresh на каждой странице
10. PWA Install Banner
