## БЛОК 3: Дедлайн при назначении исполнителя (4-5 часов)
**Приоритет: ВЫСОКИЙ**

### 3.1 Расчёт дедлайна из timeline (2-3 часа)
**Как в десктопе (crm_dialogs.py ExecutorSelectionDialog, строки 452-498, 719-734):**

- [ ] При назначении исполнителя на стадию:
  1. Загрузить timeline: `GET /api/v1/timeline/{contract_id}`
  2. Определить `stage_group` (STAGE1/STAGE2/STAGE3) по column_name
  3. Найти первый незаполненный подэтап (`actual_date` пуст)
  4. Взять `norm_days` этого подэтапа
  5. Взять `prev_actual_date` — последнюю заполненную дату перед подэтапом
  6. Рассчитать: `prev_actual_date + norm_days рабочих дней`
  7. Если нет norm_days — default `today + 7 дней`

- [ ] Функция `addWorkingDays(baseDate, days)`:
  - Пропускать субботы и воскресенья
  - Учитывать праздники РФ (список из config или API)

## ВЕРИФИКАЦИЯ: Обязательная проверка через MCP Playwright

**ОБЯЗАТЕЛЬНО** после каждого блока исправлений — проверка через MCP Playwright в реальном браузере.

### Процедура верификации

**Шаг 1: Открыть PWA**
```
mcp__playwright__browser_navigate → https://crm.festivalcolor.ru/
```

**Шаг 2: Авторизация**
```
mcp__playwright__browser_snapshot → найти поля логин/пароль
mcp__playwright__browser_fill_form → заполнить credentials
mcp__playwright__browser_click → кнопка "Войти"
```

**Шаг 3: Проверка по блоку**

#### Блок 1 (Права ролей):
- Залогиниться под разными ролями (admin, менеджер, дизайнер)
- Проверить что меню фильтруется по правам
- Проверить что route guard блокирует прямой доступ по URL
- Проверить что кнопки edit/delete скрыты для ролей без прав
- Сделать `browser_take_screenshot` как доказательство

#### Блок 2 (Workflow кнопки):
- Открыть CRM доску → выбрать карточку
- Проверить наличие кнопок workflow по роли
- Попробовать нажать «Сдать работу» / «Принять» / «На исправление»
- Скриншот каждого состояния

#### Блок 3 (Дедлайн):
- Открыть карточку → назначить исполнителя
- Проверить что дедлайн автоподставляется
- Проверить что дедлайн редактируемый

#### Блок 4 (Вариации):
- Открыть карточку → вкладка файлов
- Нажать «+» → проверить создание вкладки без file picker
- Загрузить файл в вариацию

#### Блок 5 (Фильтрация):
- Залогиниться как менеджер → проверить что видны только свои карточки
- Залогиниться как дизайнер → только назначенные на Стадии 2
- Залогиниться как руководитель → видны все

### Шаблон отчёта верификации
```
✅ / ❌ Блок N — Описание
  - Роль: admin | Страница: /crm | Результат: OK/FAIL
  - Скриншот: [описание]
  - Проблемы: [если есть]
```

### Когда делать верификацию
- **После каждого блока** — проверить свежие изменения
- **После деплоя** — полный smoke-тест всех блоков
- **При регрессии** — точечная проверка сломанного функционала
