# E2E Pywinauto тесты — покрытие (v3)

**Дата:** 2026-03-10
**Всего:** ~75 тестов, 8 файлов
**Тип:** ВСЕ тесты — РЕАЛЬНЫЕ бизнес-процессы

## Что изменилось с v2

**v2 (165 тестов):** Тесты щёлкали кнопки вкладок без бизнес-логики.
**v3 (75 тестов):** Каждый тест проходит РЕАЛЬНЫЙ бизнес-процесс — создаёт сущности, заполняет формы, проверяет валидацию, верифицирует через API.

### Ключевые отличия v3
- **CRUD операции** — создание, редактирование, удаление клиентов/договоров/сотрудников
- **Валидация** — попытки сохранить без обязательных полей → проверка ошибки
- **API верификация** — данные из UI проверяются через REST API
- **Кросс-роль** — СДП/ГАП/Дизайнер видят разные вкладки
- **Персистентное состояние** — ID созданных сущностей сохраняются между тестами
- **Быстрые клики** — time.sleep сокращены в 3-5 раз

### Скорость
- Ожидание клика: 0.3-0.8 сек (было 2-3 сек)
- Ожидание диалога: 0.5-1 сек (было 3 сек)
- Refresh: 1 сек (было 3 сек)

## Запуск

```bash
# Запустить окна + все тесты
python run_e2e.py

# Только определённые роли
python run_e2e.py --roles admin sdp

# Тесты без запуска окон (уже открыты)
python run_e2e.py --no-launch

# Не закрывать окна после тестов
python run_e2e.py --keep

# Отдельный блок
pytest tests/pywinauto/test_block2_clients.py -v --timeout=300

# Отмена: Ctrl+C в терминале
```

## Новые хелперы в multi_instance_helper.py

| Функция | Описание |
|---------|---------|
| `find_add_button(window, tooltip)` | Найти кнопку добавления |
| `find_search_button(window)` | Найти кнопку поиска |
| `get_table_rows(window)` | Строки таблицы (DataItem/ListItem) |
| `fill_dialog_field(dialog, index, text)` | Заполнить поле по индексу |
| `select_dialog_combo(dialog, index, text)` | Выбрать в ComboBox по индексу |
| `get_validation_error(pid)` | Обнаружить ошибку валидации |
| `get_question_dialog(pid)` | Найти диалог вопроса Да/Нет |
| `confirm_question(pid)` | Нажать Да |
| `deny_question(pid)` | Нажать Нет |
| `wait_for_dialog(pid, timeout)` | Ждать появления диалога |
| `fill_and_save_dialog(pid, fields, combos)` | Заполнить и сохранить |
| `click_button_by_tooltip(window, tooltip)` | Клик по tooltip |
