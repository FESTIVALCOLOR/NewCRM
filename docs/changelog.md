# Changelog — Interior Studio CRM

Журнал изменений приложения. Каждая версия содержит список изменений для публикации обновления.

---

## v1.1.0 — 2026-03-26

### Мобильная PWA — Фаза 4-5: Полная синхронизация с десктопом

#### Права доступа (Блок 1)
- Route guard по правам: 13 маршрутов с `requiresPermission`
- Проверки `can()` на 10 страницах/компонентах (CRM, договоры, клиенты, сотрудники, зарплаты, надзор)

#### Workflow CRM (Блок 2)
- Кнопки workflow с правами `complete_approval` (принять/отклонить/клиент/акт)
- Валидация перемещения карточек (запрет назад, проверка аванса)
- Диалог завершения проекта (СДАН/АВТОРСКИЙ НАДЗОР/РАСТОРГНУТ)

#### Автодедлайн (Блок 3)
- `useDeadline.js` — расчёт рабочих дней с праздниками РФ
- Автоподстановка дедлайна при назначении исполнителя из timeline

#### Фильтрация CRM (Блок 5)
- Фильтрация карточек по 7 ролям (руководитель, СДП, ГАП, менеджер, дизайнер, чертёжник, замерщик)

#### Синхронизация файлов с Яндекс.Диском
- Двусторонняя синхронизация: ЯД→CRM (scan) и CRM→ЯД (проверка удалённых)
- Кнопка «Синхронизировать» в договорах и CRM (мобиль + десктоп)
- Классификация файлов по имени (акты ПР/КД/РЧ, с подписью/без, инф. письма, доп. соглашения)
- Единая система хранения: мобиль обновляет оба хранилища (project_files + поля contracts)
- Правильная структура подпапок на ЯД (Документы/Акты, Анкета, Замер, стадии 1-3)
- Переименование папки при изменении данных договора (move-folder API)
- Автосоздание полной структуры подпапок при создании/переименовании

#### Прочие исправления
- FAB кнопки не перекрываются дашбордом
- Тип организации в списке клиентов (ИП Иванов / ООО «Ромашка») — мобиль + десктоп
- Паспорт физлица, ответственное лицо юрлица в карточке клиента
- Удаление файлов договора (только руководитель/ст. менеджер)
- Логин/пароль скрыты для не-суперюзеров
- Перемещение карточек надзора (long-press диалог)
- Глобальный поиск в header
- Фильтры архива CRM
- nginx: no-cache для index.html

## v1.0.1 — 2026-03-21

### Исправления ошибок

- **Тестовое уведомление** — обычные сотрудники теперь могут отправлять тестовое уведомление себе (раньше это мог только директор)
- **Зелёная рамка текущей стадии** — в диалоге «Данные проекта» зелёная рамка теперь корректно подсвечивает текущую стадию для всех трёх стадий (Планировочные решения, Концепция дизайна, Чертёжный проект), а не только для Стадии 2
- **Вкладка «Шаблонные проекты»** — исполнители (Дизайнер, Чертёжник) теперь видят вкладку «Шаблонные проекты» в CRM. Исправлен счётчик карточек и убрана пустая панель вкладок для пользователей без архива
- **Дедлайны подэтапов** — дедлайн на карточке канбана теперь обновляется для ВСЕХ подэтапов (ранее не обновлялся для клиентских шагов и подэтапов после 2.2)
- **Workflow: карточка застревала между подэтапами** — при согласовании клиентом диалог выбора действия больше нельзя закрыть без решения (убрана кнопка закрытия, заблокирован Escape). Добавлен retry при ошибке сети

### Новые возможности

- **Подсветка текущего подэтапа** — в таблице сроков (диалог карточки) текущий активный подэтап обведён зелёной рамкой, заголовок текущего блока подэтапов подсвечивается зелёным
- **Предупреждение о превышении нормодней** — под таблицей сроков появляется оранжевая рамка с указанием подэтапов, где нормодни были увеличены, и рекомендацией учитывать это при дальнейшей работе
- **Чат: скрытие пустых ролей** — в welcome-скрипте чата строки с незаполненными ролями (когда сотрудник не назначен) автоматически скрываются
- **Чат: проверка обязательных ролей** — при создании чата проверяется наличие обязательных сотрудников. Ошибка теперь показывает конкретные роли, которых не хватает (ранее показывалось «Проверьте подключение к серверу»):
  - Индивидуальный: Старший менеджер + СДП
  - Шаблонный: Старший менеджер + Менеджер
  - Надзор: Старший менеджер + Руководитель надзора

### Улучшения надёжности (серверная часть)

- **Централизованный workflow sync** — после каждого workflow-действия сервер автоматически проверяет и синхронизирует позицию карточки с реальным состоянием таймлайна. Это предотвращает «проваливание» карточки при переходах между подэтапами
- **Идемпотентный client-ok** — повторный вызов «клиент согласовал» (например, после краша приложения) не портит данные карточки
- **Retry при ошибке** — если серверный вызов workflow-действия не удался, предлагается повторить попытку (до 2 раз)
- **Дедупликация welcome-скрипта** — welcome-сообщение при создании чата теперь отправляется ровно один раз (ранее могло отправиться дважды)

### Для руководителя, старшего менеджера, СДП, ГАП

- **Кнопка диагностики карточки** (иконка гаечного ключа в диалоге карточки) — проверяет соответствие состояния карточки реальному таймлайну и восстанавливает при необходимости. Если карточка застряла между подэтапами — автоматически определит правильную позицию и переведёт в рабочее состояние. Показывает что именно было исправлено или подтверждает что всё в порядке
- **Запомнить меня** — на экране входа появился чекбокс «Запомнить меня». При активации программа сохраняет сессию и при следующем запуске автоматически входит без ввода логина и пароля. Сессия привязана к конкретному компьютеру, действует 30 дней. При явном выходе из программы сессия сбрасывается

### Визуальные улучшения

- **Зелёная рамка текущего подэтапа (overlay)** — в таблице сроков зелёная рамка теперь рисуется поверх таблицы единым QFrame без разрывов между ячейками. Рамка корректно следит за скроллом и ресайзом
- **Убраны скругления у ячеек таблицы** — все ячейки таблицы сроков теперь с прямыми углами
- **Предупреждение «Превышение нормодней»** — иконка заменена на SVG, блок выровнен по правому краю таблицы
- **Высота строк исполнителей на канбане** — все строки исполнителей на карточках канбана теперь одинаковой высоты, кнопка переназначения уменьшена

### Разграничение прав доступа

- **Пароль и тип оплаты** — поля «Пароль» и «Тип оплаты» в карточке сотрудника теперь видны только руководителю студии
- **Кнопки архива CRM** — «В архив» и «Из архива» доступны только руководителю и старшему менеджеру
- **Статус карточки CRM** — изменение статуса (выпадающий список) доступно только руководителю и старшему менеджеру
- **Приглашение в чат** — кнопки «Пригласить СМ/СДП/ГАП/Менеджера» доступны только руководителю, старшему менеджеру и менеджеру
- **Отправка скриптов** — кнопки start/end скриптов доступны только руководителю, старшему менеджеру и менеджеру

### Надзор — новые возможности и улучшения

- **Блок «Информация проекта»** — в карточке надзора добавлен блок с данными из договора (номер, адрес, площадь, тип/подтип проекта, агент, город)
- **Блок «Команда»** — сотрудники карточки надзора визуально сгруппированы в блок «Команда» (QGroupBox)
- **Вкладка «Таблица закупок»** — переименована из «Таблица сроков» для соответствия бизнес-логике надзора
- **Скролл таблиц надзора** — вкладки «Таблица закупок» и «Выезды» обёрнуты в QScrollArea для предотвращения переполнения при большом количестве записей
- **Расчёт дней и расхождений** — исправлен расчёт колонки «Дни» (рабочие дни между стадиями) и «Расхожд.» (отклонение факта от плана) в таблице закупок. Значение 0 теперь корректно отображается
- **Загрузка файлов** — исправлена ошибка DiskPathDoesntExistsError при загрузке файлов надзора. Добавлено рекурсивное создание папок на Яндекс.Диске

### Надзор — стилизация

- **Кнопка «Данные карточки»** — цвет кнопки на канбане надзора приведён к серому (#E0E0E0), как в основном CRM
- **Кнопка «Добавить запись»** — белый фон с зелёным текстом/рамкой, иконка plus зелёная
- **Кнопка «Переназначить»** — высота 28px, единый стиль с основным CRM
- **Диалог начала надзора** — стиль календаря приведён к стандартному (CALENDAR_STYLE), кнопки: серая отмена + зелёное сохранение
- **Нижние кнопки** — удалить/сохранить/закрыть: высота 36px с min-height/max-height фиксацией
- **Кнопка «Создать чат»** — цвет текста изменён с белого на #333333

### Исправления CRM

- **Блокировка дат для завершённых строк** — в таблице сроков карандаш редактирования заблокирован для строк со статусом «В срок», «Просрочен», «Пропущен»
- **Диагностика шаблонных проектов** — кнопка диагностики теперь корректно работает для шаблонных проектов без предварительно созданного workflow state (создаётся автоматически)
- **Фокус ComboBox в таблицах** — QComboBox внутри ячеек таблиц надзора теперь корректно реагирует на клик (setFocusPolicy StrongFocus)
- **Двойное сохранение** — предотвращено повторное срабатывание editingFinished при пересборке таблицы закупок

### Исправления стабильности

- **Автологин при закрытии крестиком** — при закрытии окна через крестик (X) программа больше не деактивирует серверную сессию, если включена функция «Запомнить меня». Автологин теперь работает корректно при повторном запуске
- **Диалоги обновления** — увеличено поле описания изменений, changelog отображается со скроллом и переносами строк, добавлена кнопка автоимпорта из changelog
- **Возобновление карточки надзора** — карточка теперь выходит из приостановки с первого клика. Исправлена проблема кэширования: после pause/resume кэш карточек надзора инвалидируется, refresh показывает актуальное состояние
- **Offline-очередь надзора** — операции pause/resume/reset_stage_completion теперь корректно синхронизируются через соответствующие API endpoint-ы (ранее отправлялись как generic update)
