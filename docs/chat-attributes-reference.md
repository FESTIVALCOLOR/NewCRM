# Справочник атрибутов чатов — PWA vs Десктоп

> Все поля, которые используются в клиентских и сотруднических чатах.
> Описания — простым языком для новичка.
> Столбец **«Десктоп (PyQt5)»** показывает, какое поле или метод реализует тот же функционал в десктопном клиенте, и есть ли оно вообще.

Условные обозначения:
- ✅ — есть, реализовано
- ❌ — отсутствует (нужно добавить / см. таблицу требований)
- ⚠️ — реализовано иначе (описание рядом)
- `—` — N/A, концепция не применима к десктопу

## 1. Объект «Чат» (`Chat`)

| Атрибут | Тип | Откуда приходит | Что делает | Десктоп (PyQt5) |
|---|---|---|---|---|
| `id` | `int` | `GET /api/v1/chats/` | Уникальный номер чата. Используется во всех запросах как часть URL `/chats/{id}/...` | ✅ `id` — используется везде |
| `title` | `string` | сервер | Название чата — отображается в шапке и в списке чатов | ✅ `title` |
| `chat_type` | `string` | сервер | Тип чата: `"client"` (чат с клиентом) или `"employee"` (чат сотрудников). Определяет, какой интерфейс показывать | ✅ `chat_type` |
| `unread_count` | `int` | сервер | Сколько сообщений ещё не прочитано. Показывается красным кружком (бейджем) на иконке чата | ✅ `unread_count` + сигнал `unread_changed` |
| `last_message` | `string` | сервер | Текст последнего сообщения — короткое превью в списке чатов, чтобы видеть о чём разговор без открытия | ✅ `last_message` |
| `member_count` | `int` | сервер | Количество сотрудников-участников чата | ✅ `member_count` |
| `guest_count` | `int` | сервер | Количество клиентов (гостей) в чате | ✅ `guest_count` |
| `messages` | `list[Message]` | `GET /api/v1/chats/{id}/messages` | Массив всех сообщений чата. Загружается постранично (limit/offset) | ✅ загружается через `get_chat_messages()` |
| `members` | `list[Member]` | `GET /api/v1/chats/{id}` → поле внутри | Список участников чата. Открывается в диалоге «Участники» | ✅ `members` в `ChatMembersDialog` |
| `client_access_token` | `string` | сервер | Секретный токен для генерации ссылки-приглашения клиенту. Ссылка выглядит как `/c/{token}` | ✅ `client_access_token` в `ClientChatsTab` |
| `first_unread_message_id` | `int \| null` | сервер | ID первого непрочитанного сообщения. Приложение прокручивает чат до этого места и рисует разделитель «Новые сообщения» | ✅ `first_unread_message_id` → `_scroll_to_first_unread()` |
| `pinned_messages` | `list[Message]` | сервер | Список закреплённых сообщений (максимум 10). Показываются в жёлтой полосе вверху чата | ✅ `pinned_messages` → `_pinned_panel` |
| `crm_card_id` | `int \| null` | сервер | ID CRM-карточки, к которой привязан чат. Нужен для загрузки данных карточки и кнопки «Скопировать в карточку» | ✅ `crm_card_id` в `ChatRoomWidget` |
| `yandex_folder_path` | `string \| null` | сервер | Путь папки на Яндекс.Диске, связанной с чатом. Используется для сохранения файлов из чата | ✅ кнопка «Папка ЯД» в шапке чата → `_yd_folder_btn` / `_open_yd_folder()` |
| `requires_registration` | `bool` | сервер | Нужна ли регистрация гостю при входе по ссылке. Если `true` — гостя попросят ввести имя/телефон | `—` только для PWA-гостей; в десктопе нет гостевого входа |

## 2. Объект «Сообщение» (`Message`)

| Атрибут | Тип | Откуда приходит | Что делает | Десктоп (PyQt5) |
|---|---|---|---|---|
| `id` | `int` | сервер | Уникальный номер сообщения. Используется для ответа (`reply_to_id`), редактирования, удаления, закрепления | ✅ `id` |
| `message_type` | `string` | сервер | Тип: `"text"`, `"image"`, `"file"`, `"voice"`, `"system"`. Определяет как рисовать пузырь — текст, картинка, файл, аудио или системное уведомление | ⚠️ `text/image/file/system` — полностью; `voice` — заглушка (кнопка ▶ без воспроизведения) |
| `content` | `string \| null` | сервер | Текст сообщения (только для `message_type = "text"`) | ✅ `content` |
| `sender_employee_id` | `int \| null` | сервер | ID сотрудника, который отправил сообщение. Если совпадает с текущим пользователем — пузырь рисуется справа (зелёный) | ✅ `sender_employee_id` → `is_own` |
| `sender_guest_token` | `string \| null` | сервер | Токен гостя-отправителя. Если поле не пустое — сообщение от клиента; показывается зелёный чип «клиент» | ✅ `sender_guest_token` → чип «клиент» в `_build_header()` |
| `sender_display_name` | `string` | сервер | Имя отправителя, которое показывается над пузырём | ✅ `sender_display_name` |
| `sender_phone` | `string \| null` | сервер | Телефон клиента-гостя. Показывается рядом с чипом «клиент» (tooltip или мелкий текст). В мобиле — только если есть право `chat.client.show_phone` | ⚠️ `sender_phone` показывается без проверки права `chat.client.show_phone` → см. §13 |
| `file_name` | `string \| null` | сервер | Имя файла (для `image` и `file`). Отображается в пузыре рядом с иконкой | ✅ `file_name` |
| `file_url` | `string \| null` | сервер | Прямая ссылка для скачивания файла | ✅ `file_url` |
| `file_size` | `int \| null` | сервер | Размер файла в байтах. Используется при валидации перед загрузкой | ✅ отображается мелким текстом под именем файла → `_build_file_row()` |
| `yandex_path` | `string \| null` | сервер | Путь файла на Яндекс.Диске (`disk:/CRM/...`). Нужен для стриминга изображений через backend и кнопки «Скопировать в карточку» | ✅ `yandex_path` в стриминге и `_show_copy_to_card_dialog()` |
| `created_at` | `datetime string` | сервер | Дата и время отправки. Отображается в правом нижнем углу пузыря в формате `ЧЧ:ММ` | ✅ `created_at` → `_build_footer()` |
| `is_deleted` | `bool` | сервер | Если `true` — сообщение удалено. Вместо текста показывается «Сообщение удалено» курсивом | ✅ `is_deleted` |
| `is_edited` | `bool` | сервер | Если `true` — сообщение было изменено. Рядом с временем показывается маленькая пометка «изм.» | ✅ `is_edited` |
| `is_pinned` | `bool` | сервер | Если `true` — сообщение закреплено. Попадает в полосу закреплённых сообщений вверху чата | ✅ `is_pinned` |
| `reply_preview` | `object \| null` | сервер | Объект цитируемого сообщения (при ответе). Показывается серой плашкой над текстом. Подробнее — раздел 3 | ✅ `reply_preview` используется полностью, включая миниатюру изображения |
| `group_id` | `string \| null` | сервер | Уникальный ID группы для нескольких изображений, отправленных вместе. Объединяет их в галерею-сетку | ✅ `group_id` → `ChatGalleryWidget` |
| `_uploading` | `bool` | локальный | Локальный флаг (не с сервера). Пока файл грузится — показывает спиннер в пузыре | ✅ плейсхолдер «Загрузка…» добавляется до получения ответа сервера → `_add_upload_placeholders()` |
| `_previewUrl` | `string` | локальный | Локальный URL превью (blob:// или base64). Даёт возможность показать картинку до завершения загрузки на сервер | ✅ превью из локального файла отображается в плейсхолдере → `_add_upload_placeholders()` |

## 3. Объект «Цитата» (`reply_preview`)

Вложен внутрь `Message.reply_preview`.

| Атрибут | Тип | Что делает | Десктоп (PyQt5) |
|---|---|---|---|
| `id` | `int` | ID оригинального сообщения. По клику на цитату прокручивает чат до этого сообщения | ⚠️ не читается из `reply_preview`; вместо него используется `Message.reply_to_id` — результат тот же |
| `message_type` | `string` | Тип цитируемого сообщения. Если `"image"` — показывает «[Изображение]», если `"file"` — «[Файл]» | ✅ `reply_preview.message_type` |
| `content` | `string \| null` | Текст цитируемого сообщения. Отображается в серой плашке-цитате | ✅ `reply_preview.content` |
| `sender_display_name` | `string` | Имя автора цитируемого сообщения | ✅ `reply_preview.sender_display_name` |
| `yandex_path` | `string \| null` | Если цитируется изображение — загружает его как маленькую миниатюру в плашке цитаты | ✅ загружается async через `QNetworkAccessManager`, показывается 40×40 px → `_build_text()` |

## 5. Объект «Скрипт» (`Script`)

Используется в диалоге «Отправить скрипт».

| Атрибут | Тип | Откуда приходит | Что делает | Десктоп (PyQt5) |
|---|---|---|---|---|
| `id` | `int` | `GET /api/v1/messenger-scripts/` | Уникальный номер скрипта | ✅ `id` (неявно, через выбор в `QListWidget`) |
| `name` | `string \| null` | сервер | Название скрипта. Отображается в списке для выбора | ✅ `name` |

| `message_template` | `string` | сервер | Текст шаблона с переменными в фигурных скобках, например: `"Здравствуйте, {client_name}! Ваш адрес: {address}."` Перед отправкой переменные заменяются реальными данными | ✅ `message_template` → `_fill_vars()` |

| `{area}` | `card.area` | Площадь объекта (м²) | ✅ `card.area` |

| `{deadline}` | `card.deadline` | Срок выполнения | ✅ `card.deadline` |
| `{senior_manager}` | `card.senior_manager_name` | Имя старшего менеджера | ✅ `card.senior_manager_name` |
| `{manager_name}` | `card.manager_name` | Имя менеджера | ✅ `card.manager_name` |
| `{sdp}` | `card.sdp_name` | Имя СДП | ✅ `card.sdp_name` |
| `{gap}` | `card.gap_name` | Имя ГАПа | ✅ `card.gap_name` |
| `{surveyor}` | `card.surveyor_name` | Имя замерщика | ✅ `card.surveyor_name` |
| `{sender_name}` | `employee.full_name` | Имя отправляющего сотрудника | ✅ `employee.get('full_name')` |

## 10. Параметры URL и localStorage

| Ключ | Где хранится | Что делает | Десктоп (PyQt5) |
|---|---|---|---|
| `chatId` | URL param | ID чата из адресной строки (`/chats/42`). Используется для загрузки конкретного чата | `—` Qt-приложение не использует URL-адреса |
| `token` | URL param | Токен гостя из ссылки-приглашения (`/c/{token}`). По нему идентифицируется клиент без логина | `—` нет гостевого входа в десктопе |
| `access_token` | localStorage | JWT токен сотрудника. Передаётся в WebSocket-соединение для авторизации | ⚠️ хранится в памяти (`api_client.token`), не в localStorage |
| `client_name` | localStorage | Имя клиента. Сохраняется после регистрации гостя и используется при отправке файлов | `—` только для PWA-гостей |
| `chat_member_token_{token}` | localStorage | Персональный токен участника. Сохраняется после первого входа по ссылке, чтобы не вводить имя снова | `—` только для PWA-гостей |
| `chat_last_read_{token}` | localStorage | ID последнего прочитанного сообщения для гостя. Хранится локально, так как у гостя нет аккаунта | `—` только для PWA-гостей |
