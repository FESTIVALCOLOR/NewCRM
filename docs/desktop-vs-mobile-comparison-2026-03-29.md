## Offline режим

| Аспект | Десктоп (`offline_manager.py`) | Мобиль (`offlineQueue.js`) |
|--------|-------------------------------|---------------------------|
| Хранилище | SQLite таблица `operations_queue` | IndexedDB (браузер) |
| Безопасность | HMAC-подписанные операции | Без подписи |
| Типы операций | 15+ специфичных (client, contract, crm_card...) | Общий механизм |
| Retry | Backoff с логированием | До 3 попыток |
| Индикация | Значок в заголовке | OfflinePage + badge |
| Qt-интеграция | Сигналы `sync_progress/completed/failed` | Promise-based callbacks |

## Реальные различия платформ

### Уникальное в мобиле (нет в десктопе)
1. **Голосовые заметки** — VoiceRecorder.vue (MediaRecorder API → ЯД)
2. **Профиль пользователя** — просмотр/редактирование своих данных
3. **WebSocket real-time** — мгновенные обновления канбана без polling
4. **Optimistic UI** — карточка перемещается мгновенно с откатом при ошибке
5. **PWA** — install на экран, OfflinePage, ServiceWorker обновления

### Уникальное в десктопе (нет в мобиле)
1. **Глобальный поиск** — `ui/global_search_widget.py`
2. **Галерея вариаций дизайна** — `ui/variation_gallery_widget.py`
3. **Экспорт отчётов в Excel** — детальные таблицы с форматированием
4. **Файлы: превью-галерея** — миниатюры (мобиль использует браузер папок)

### Разная реализация (суть одинакова)
- **Файловый менеджер**: десктоп — галерея/список; мобиль — навигация по папкам
- **Offline**: десктоп — SQLite+HMAC; мобиль — IndexedDB
- **Обновление приложения**: десктоп — `update_dialogs.py`; мобиль — ServiceWorker в ProfilePage
- **Отчёты**: десктоп — таблицы сравнения + топ-5; мобиль — графики

## Вывод

Мобильная PWA — **почти полнофункциональный** аналог десктопа. Покрывает 30 из 39 функций полностью. Четыре функции реализованы по-разному (одинаковая суть). Только 4 функции есть исключительно в десктопе (поиск, вариации, Excel, превью-галерея).

Мобиль превосходит десктоп в: real-time обновления (WebSocket), голосовые заметки, optimistic UI, PWA-возможности.
