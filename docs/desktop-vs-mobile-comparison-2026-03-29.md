## Общий обзор платформ

| Параметр | Десктоп (PyQt5) | Мобиль (Quasar/Vue3) |
|----------|-----------------|----------------------|
| Строк кода | ~67 500 (ui/) + ~18 800 (utils/) | ~14 400 (mobile/src/) |
| Модулей/страниц | 47 UI файлов | 21 страница + 12 компонентов |
| Целевая аудитория | Офисная работа, администраторы | Полевая работа, исполнители |
| UX парадигма | Mouse + keyboard, множество окон | Touch + swipe, одно окно |
| Offline хранилище | SQLite + HMAC-подписанная очередь | IndexedDB (браузер) |
| Права доступа | `utils/permissions.py` (функции + кэш) | `usePermission.js` (Composable + Pinia) |
| Real-time | SyncManager (polling 30 сек) | WebSocket + useWebSocket.js |
| Распространение | .exe (Windows) / .app (macOS) | PWA (install на домашний экран) |

## Ключевые выводы

### Десктоп — сильные стороны
- Полная функциональность для admin/manager ролей
- Детальные отчёты с экспортом PDF (полное форматирование)
- Матрица прав, тарифы, нормирование дней
- Глобальный поиск по всем сущностям
- Аналитика сотрудников (топ-5, сравнение по ролям)
- Мощный offline-режим (HMAC, 15+ типов операций)

### Мобиль — сильные стороны
- Голосовые заметки (уникальная функция)
- WebSocket real-time обновления (мгновенно, без polling)
- Optimistic UI (немедленный отклик без ожидания сервера)
- PWA (работает как нативное приложение, offline через IndexedDB)
- Компактный UX для полевой работы (touch, swipe, bottom sheets)
- Профиль пользователя
