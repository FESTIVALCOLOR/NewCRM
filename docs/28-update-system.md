# Система обновления программы Interior Studio CRM

## Общее описание

Программа имеет встроенную систему обновления через Яндекс.Диск. Обновления распространяются в виде EXE-файлов, а информация о версиях хранится в файле `version.json` в облачной папке.

**Два режима работы:**
- **Пользовательский** — проверка и установка обновлений (доступен всем)
- **Административный** — управление версиями и публикация обновлений (только для Руководителя студии)

---

## 1. Проверка обновлений (для всех пользователей)

### Где находится кнопка
Кнопка обновления расположена в **статусной строке** (нижняя часть окна), справа от надписи «Версия: X.Y.Z». Выглядит как маленькая иконка обновления (⟳).

### Как проверить наличие обновлений
1. Нажмите кнопку **⟳** в правом нижнем углу окна программы
2. В статусной строке появится надпись «Проверка обновлений...»
3. Программа обратится к Яндекс.Диску и сравнит вашу версию с последней доступной

### Возможные результаты проверки

| Результат | Что происходит |
|-----------|---------------|
| **Обновление найдено** | Открывается диалог с информацией о новой версии |
| **Обновлений нет** | Сообщение «У вас установлена последняя версия программы» |
| **Проверка отключена** | Сообщение «Проверка обновлений отключена в настройках» |
| **Ошибка сети** | Сообщение с описанием ошибки (нет интернета, сервер недоступен и т.д.) |

### Установка обновления
Если обновление найдено, откроется диалог со следующей информацией:
- **Номер новой версии** (например, 2.0.0)
- **Дата выпуска**
- **Размер файла** (в МБ)
- **Описание изменений** (что нового в версии)

**Кнопки:**
- **«Загрузить и установить»** — начинает скачивание и установку
- **«Позже»** — закрывает диалог (обновление можно установить позже)

### Процесс установки
1. Нажмите **«Загрузить и установить»**
2. Появится прогресс-бар с отображением загрузки (в МБ и процентах)
3. После загрузки программа **автоматически закроется**
4. Откроется окно командной строки с сообщением «Обновление Interior Studio CRM...»
5. Старый EXE-файл заменится на новый
6. Программа **автоматически запустится** с обновлённой версией

> **Важно:** Во время обновления не закрывайте окно командной строки. Процесс занимает несколько секунд.

## 2. Управление версиями (только для администратора)

### Доступ
Диалог управления доступен только пользователям с разрешением `access.admin` (роль «Руководитель студии»).

**Как открыть:** удерживая клавишу **Shift**, нажмите кнопку обновления (⟳) в статусной строке.

### Диалог «Управление версией и обновлениями»

Диалог состоит из трёх блоков:

#### Блок 1: Сверка версии с сервером
- Показывает текущую версию клиента и версию на сервере
- Кнопка **«Проверить версию сервера»** — запрашивает версию через API (`/api/v1/version`)
- Результат: ✔ совпадает (зелёный) или ✘ не совпадает (красный)

#### Блок 2: Изменение версии
- Поле ввода для новой версии (формат **X.Y.Z**, например `1.2.0`)
- Кнопка **«Сохранить»** — записывает новую версию в `config.py`
- После сохранения требуется **перезапуск программы**

#### Блок 3: Загрузка обновления на Яндекс.Диск
1. Нажмите **«Выбрать .exe»** — выберите собранный EXE-файл обновления
2. Заполните поле **«Описание изменений»** (что нового в этой версии)
3. Укажите **версию** в блоке 2 (если не указана, используется текущая)
4. Нажмите **«Загрузить обновление на Яндекс.Диск»**
5. Дождитесь завершения загрузки (индикатор прогресса)

**Что происходит при загрузке:**
- EXE-файл загружается в папку `disk:/CRM/Обновления/` с именем `InteriorStudio_X.Y.Z.exe`
- Файл `version.json` автоматически обновляется с метаинформацией о версии
- После загрузки все пользователи смогут получить обновление

## 3. Полный цикл выпуска обновления (для администратора)

### Шаг 1: Подготовка
1. Убедитесь, что все изменения в коде протестированы и закоммичены
2. Если были серверные изменения — выполните Docker rebuild на production

### Шаг 2: Сборка EXE
```bash
.venv\Scripts\pyinstaller.exe InteriorStudio.spec --clean --noconfirm
```
Готовый файл появится в папке `dist/InteriorStudio.exe`.

### Шаг 3: Обновление версии
1. Откройте диалог управления версиями (Shift + кнопка обновления)
2. Введите новую версию (например, `1.1.0`) и нажмите **«Сохранить»**
3. **Пересоберите EXE** после изменения версии (чтобы новая версия попала в сборку)

### Шаг 4: Публикация обновления
1. В диалоге управления нажмите **«Выбрать .exe»** → укажите собранный файл из `dist/`
2. Заполните описание изменений
3. Нажмите **«Загрузить обновление на Яндекс.Диск»**
4. Дождитесь сообщения об успешной загрузке

### Шаг 5: Проверка
1. Нажмите кнопку обновления (без Shift) — должно появиться уведомление о новой версии
2. Попросите другого сотрудника проверить обновление на своём компьютере

## 4. Техническая архитектура

### Хранилище обновлений (Яндекс.Диск)
```
disk:/CRM/Обновления/
├── version.json                    # Метаинформация о версиях
├── InteriorStudio_1.0.0.exe        # Файл версии 1.0.0
├── InteriorStudio_1.1.0.exe        # Файл версии 1.1.0
└── InteriorStudio_2.0.0.exe        # Файл версии 2.0.0
```

### Формат version.json
```json
{
  "latest_version": "2.0.0",
  "versions": {
    "2.0.0": {
      "release_date": "2026-03-16",
      "size_mb": "85.5",
      "changelog": "Новые функции: аналитика сотрудников, система уведомлений",
      "file_name": "InteriorStudio_2.0.0.exe"
    },
    "1.0.0": {
      "release_date": "2026-01-15",
      "size_mb": "82.0",
      "changelog": "Первая версия",
      "file_name": "InteriorStudio_1.0.0.exe"
    }
  }
}
```

### Конфигурация (config.py)
| Параметр | Значение | Описание |
|----------|----------|---------|
| `APP_VERSION` | `"1.0.0"` | Текущая версия программы |
| `UPDATE_CHECK_ENABLED` | `True` | Включена ли проверка обновлений |
| `UPDATE_CHECK_INTERVAL` | `3600` | Интервал автопроверки (секунды) |
| `UPDATE_YANDEX_PUBLIC_KEY` | `"SmxiWfUUEt8oEA"` | Публичный ключ папки обновлений |
| `YANDEX_DISK_UPDATES` | `disk:/CRM/Обновления` | Путь папки на Яндекс.Диске |

### Ключевые файлы
| Файл | Назначение |
|------|-----------|
| `utils/update_manager.py` | Логика проверки, загрузки и установки обновлений |
| `ui/update_dialogs.py` | Диалоги: `UpdateDialog` (пользователь) и `VersionDialog` (админ) |
| `ui/main_window.py` | Интеграция кнопки обновления в статус-бар |
| `config.py` | Настройки версионирования |

### Механизм установки
1. Новый EXE скачивается во временную папку (`%TEMP%/InteriorStudio_X.Y.Z.exe`)
2. Создаётся batch-скрипт `update_crm.bat` в `%TEMP%`
3. Batch-скрипт запускается в новом окне консоли
4. Текущая программа завершается (`sys.exit(0)`)
5. Скрипт ждёт 2 секунды (чтобы процесс освободил файл)
6. Старый EXE заменяется новым (`move /y`)
7. Новая версия запускается автоматически
8. Batch-скрипт удаляет себя

## 5. Устранение проблем

| Проблема | Решение |
|----------|---------|
| «Не удалось проверить обновления» | Проверьте подключение к интернету. Яндекс.Диск должен быть доступен |
| «Публичный ключ не настроен» | В `config.py` проверьте `UPDATE_YANDEX_PUBLIC_KEY` |
| Обновление не запускается после загрузки | Проверьте, что антивирус не блокирует `update_crm.bat` в папке `%TEMP%` |
| Версия клиента и сервера не совпадают | Обновите серверную версию в `server/config.py` и пересоберите Docker |
| Кнопка Shift+клик не открывает управление | Убедитесь, что у вас роль с разрешением `access.admin` |
| «Яндекс.Диск токен не настроен» | Установите переменную окружения `YANDEX_DISK_TOKEN` с OAuth-токеном |
